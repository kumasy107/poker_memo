# Poker Memo

テキサスホールデムで同卓しているプレイヤー（自分含む）のアクションをハンド単位で手早く記録するための、自宅PC + スマホだけで使うクローズドなWebアプリです。

## できること

- セッション（1回のゲーム）を作成し、参加プレイヤーを登録
- ハンドごとに、プリフロップ/フロップ/ターン/リバー各ストリートでの各プレイヤーのアクション（フォールド/チェック/コール/ベット/レイズ/オールイン、金額）をタップで記録
- ボードカード・ハンド（ホールカード）をカードピッカーでタップ入力
- ポットサイズ・勝者・自由メモをハンド単位で記録
- 過去のセッション・ハンドを一覧・見返し可能
- プレイヤー情報はセッションごとの使い捨て（長期の名簿管理はしない）

データは自宅PC上のSQLiteファイル（`data/poker_memo.db`）にのみ保存され、外部サービスには一切送信されません。

## セットアップ（自宅PC）

前提: Node.js 18以上

```bash
npm install
npm start
```

デフォルトで `http://<PCのIP>:3000` で待ち受けます。ポートを変えたい場合は `PORT=8080 npm start` のように指定してください。

## Tailscaleでクローズドに公開する

このアプリはインターネットには公開せず、Tailscale の tailnet（自分の端末だけが繋がる仮想ネットワーク）経由でPCとスマホから閲覧する構成を想定しています。

1. **PC側**
   - [Tailscale](https://tailscale.com/download) をインストールし、自分のアカウントでログイン
   - `npm start` でアプリを起動（`HOST` は変更不要。デフォルトの `0.0.0.0` はTailscaleインターフェースを含む全インターフェースで待ち受けますが、ルーターのポート開放をしない限りインターネットからは到達できません）
   - PCのTailscale IP（`100.x.x.x`）または MagicDNS 名（例: `mypc.tailxxxx.ts.net`）を確認（`tailscale ip -4` コマンドやTailscaleアプリの画面で確認できます）

2. **スマホ側**
   - App Store / Google Play から Tailscale アプリをインストールし、同じアカウントでログイン
   - ブラウザで `http://<PCのTailscale IP>:3000`（または `http://<MagicDNS名>:3000`）にアクセス

3. **重要な注意**
   - ルーターのポートフォワーディングは絶対に設定しないでください（設定するとインターネットに公開されてしまいます）
   - Tailscaleの管理画面で、tailnetに自分の端末（PCとスマホ）以外を招待しないようにしてください
   - PCの電源が入っていてアプリが起動している間だけアクセス可能です

外出先からも使いたい場合、Tailscaleに接続してさえいればスマホの回線からでも上記URLでアクセスできます（Tailscaleがオンラインの端末同士をVPNのように直結してくれるため）。

## 追加の安全策（任意）: 簡易パスワード

Tailscaleでネットワークを閉じていれば通常は不要ですが、念のためアプリ自体にもPIN/パスワードを掛けたい場合は環境変数 `APP_PASSWORD` を設定して起動してください。

```bash
APP_PASSWORD=好きなパスワード npm start
```

設定すると、初回アクセス時にパスワード入力画面が表示され、Cookieでログイン状態が保持されます（サーバー再起動でログアウトされます）。設定しなければパスワード画面は出ません。

## 常時起動しておきたい場合

PCを再起動しても自動でアプリが立ち上がるようにしたい場合は、`pm2` や OS標準のサービス管理（systemd / タスクスケジューラ等）でこのプロセス（`npm start` 相当）を登録することを検討してください。

## データのバックアップ

全データは `data/poker_memo.db` の1ファイルに入っています（`.gitignore` によりGit管理対象外）。バックアップしたい場合はこのファイルをコピーしてください。

## 技術構成

- サーバー: Node.js + Express
- データベース: SQLite（`better-sqlite3`）
- フロントエンド: ビルド不要のバニラJS/HTML/CSS（スマホでの片手操作を意識したUI）
